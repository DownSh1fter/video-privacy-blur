# Video Privacy Blur

[English version](README.md).

Локальное приложение компьютерного зрения: находит лица и автомобильные номерные знаки в видео и размывает эти области. Проект посвящён защите приватности при обработке видео. Он не устанавливает личность человека и не считывает текст номера.

## Статус проекта

**Шаг 0 — постановка задачи и план оценки:** описан.

**Шаг 1 — запускаемый baseline для видео:** реализован на Haar Cascade из OpenCV и Gaussian blur. Это традиционный лёгкий baseline, а не глубокая модель, которую мы собираемся дообучить.

**Дальше:** запустить baseline на коротком ролике, записать пропуски и выбрать датасет с подходящей лицензией и современную предобученную модель для дообучения.

## Что мы строим

1. Получаем кадры из загруженного видеофайла.
2. Находим ограничивающие рамки лица и номерного знака.
3. Немного расширяем каждую рамку и размываем область.
4. Показываем результат или сохраняем обезличенное видео.
5. Дообучаем готовый детектор номерных знаков и сравниваем его с baseline.

Локальное приложение Streamlit записывает загруженный ролик во временную локальную папку, обрабатывает его, возвращает обезличенный MP4 и удаляет временные файлы. Приложение не отправляет кадры на удалённый сервис. В выходном видео baseline пока нет звуковой дорожки.

## Запуск на Windows

Дважды щёлкните `start-app.bat`. При первом запуске скрипт создаст локальное окружение `.venv`, установит зависимости проекта и откроет приложение в браузере. Выберите короткий ролик MP4/AVI/MOV/MKV. Для диагностики укажи секунду, где хорошо виден объект, и нажми «Показать найденные области»: зелёные рамки покажут, что именно нашёл Haar Cascade. Затем нажми «Обработать видео». Внимательно проверь результат: детектор может пропустить лицо или номер, а в выходном MP4 нет звука. Подробная инструкция — [шаг 2: диагностика ошибок](docs/STEP_02_ERROR_ANALYSIS.ru.md).

Ручной запуск:

```powershell
python -m venv .venv
.venv\\Scripts\\Activate.ps1
python -m pip install -e .
python -m streamlit run src/privacy_blur/app.py
```

## Чему учит этот проект

Проект охватывает поиск и разметку данных, transfer learning, разделение данных на обучение, валидацию и тест, метрики детекции объектов, анализ ошибок, задержку инференса и видеопайплайн целиком. Мы измерим, находит ли модель чувствительные области и подходит ли скорость обработки для живого потока.

## Принципы оценки

- Делить данные по исходным видео или сессиям съёмки, а не по соседним кадрам. Соседние кадры очень похожи, поэтому при случайном разбиении возникает утечка данных между выборками.
- Использовать validation для выбора порога уверенности и настроек; test оставить для финального сравнения.
- Публиковать precision и recall по классам, mAP@0.5, скорость инференса, примеры пропусков и ложных обнаружений.
- Для приватности особенно важен recall: если модель пропустила лицо или номер, он останется виден. Также будем учитывать ложные обнаружения, потому что избыточное размытие мешает просмотру видео.
- Для каждого эксперимента записывать модель, версию данных, разбиение, размер изображения, порог, оборудование и random seed.

## Границы и ограничения

Детектор находит лицо или номер, но не устанавливает личность, не распознаёт лица и не применяет OCR (оптическое распознавание символов) к номерам. Модель может ошибаться на мелких, закрытых, снятых под углом, тёмных или смазанных движением объектах. Перед публикацией обработанное видео нужно проверить.
