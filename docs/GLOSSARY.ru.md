# Словарь терминов

- **Anonymization (обезличивание):** изменение изображения, чтобы чувствительную деталь (здесь лицо или номер) было труднее распознать.
- **Bounding box / bbox (ограничивающая рамка):** прямоугольник вокруг объекта, обычно записанный координатами `(x_min, y_min, x_max, y_max)`.
- **Confidence score (оценка уверенности):** оценка модели для найденного объекта. Это сигнал для ранжирования, а не автоматически откалиброванная вероятность.
- **Gaussian blur (размытие по Гауссу):** фильтр сглаживания, заменяющий мелкие детали локальными усреднёнными значениями; в проекте скрывает найденную область.
- **Haar Cascade (каскад Хаара):** традиционный классификатор, который объединяет простые признаки изображения в несколько этапов. Он быстрый, но менее устойчивый, чем современные глубокие модели.
- **OCR (optical character recognition, оптическое распознавание символов):** перевод текста на изображении в символы. В этом проекте находим рамку номера, но не читаем его текст.
- **Data leakage (утечка данных):** влияние validation или test данных на обучение либо выбор настроек. Случайное разделение соседних кадров видео может вызвать утечку.
- **Detection (детекция):** предсказание класса объекта и его расположения на изображении.
- **False negative / FN (пропуск):** размеченное лицо или номер, которое детектор не нашёл.
- **False positive / FP (ложное обнаружение):** предсказанное лицо или номер, которого на самом деле нет.
- **Fine-tuning (дообучение):** продолжение обучения с готовых весов на примерах конкретной задачи.
- **FPS (кадров в секунду):** количество видеокадров, обрабатываемых за секунду.
- **Inference (инференс):** применение обученной модели к новым изображениям или кадрам.
- **IoU (Intersection over Union, пересечение над объединением):** площадь пересечения предсказанной и размеченной рамок, делённая на площадь их объединения.
- **mAP (mean Average Precision):** средняя точность по классам объектов и ранжированию детекций. В `mAP@0.5` для совпадения рамок используется IoU 0.5.
- **Precision (точность положительных предсказаний):** `TP / (TP + FP)`. Какая доля найденных объектов размечена верно?
- **Pretrained model (предобученная модель):** модель, веса которой ранее обучили на другом датасете.
- **Recall (полнота):** `TP / (TP + FN)`. Какую долю размеченных объектов детектор нашёл?
- **Transfer learning (перенос обучения):** повторное использование признаков предобученной модели в близкой задаче; часто заменяют её голову детекции и дообучают модель.
- **Train / validation / test:** примеры для обновления весов / выбора настроек / финальной проверки обобщения.
- **Threshold (порог):** минимальная оценка, при которой обнаружение принимается. Низкий порог обычно повышает recall и может увеличить ложные срабатывания.
- **Throughput (пропускная способность):** объём данных, обрабатываемый за единицу времени; для видео обычно измеряется в FPS.
