# Источники данных и моделей

## Текущий baseline

Текущая версия загружает XML-файлы предобученных Haar Cascade, которые входят в пакет OpenCV:

- каскад лиц анфас: `haarcascade_frontalface_default.xml`;
- каскад номеров российского типа: `haarcascade_russian_plate_number.xml`.

Пакет OpenCV предоставляет эти файлы моделей; проект не распространяет их копии. См. [официальное руководство OpenCV по каскадам](https://docs.opencv.org/5.0/tutorials_contrib/xobjdetect/cascade_classifier/cascade_classifier.html): там описана загрузка и применение предобученных каскадов. Классификатор номеров регионально специализирован и не является универсальным.

## Статус обучающих данных

Датасет для обучения пока не выбран и не скачан. До обучения мы отдельно проверим лицензии изображений и разметки, запишем URL и версии источников, а исходные видео и большие архивы изображений не будем добавлять в Git. Лицензия датасета не обязательно автоматически разрешает распространять любые веса модели, обученные на нём; условия весов тоже проверим.

## Критерии выбора датасета

- Есть разметка ограничивающих рамок вокруг целой области номерного знака.
- Есть разные размеры номеров, ракурсы, освещение и расстояния до камеры.
- У изображений и аннотаций указаны явные лицензии.
- Данные можно разделить по исходным источникам или роликам, чтобы соседние кадры не попали в train и test одновременно.
- Не нужно добавлять личные или идентифицирующие видео пользователя в репозиторий.
